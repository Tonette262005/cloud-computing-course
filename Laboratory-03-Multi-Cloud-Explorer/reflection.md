
# Mission Reflection

## Reflection

Among the three cloud platforms, Google Cloud Platform impressed me the most because of its capabilities in Artificial Intelligence, Machine Learning, data processing, and Kubernetes. I found it interesting how cloud platforms provide different services that can support modern applications and business operations. This activity helped me understand that cloud computing is not only about storing files online but also about computing, networking, databases, security, and application development.

AWS, Microsoft Azure, and Google Cloud have many similarities. All three platforms provide services for computing, storage, networking, databases, identity management, and application deployment. However, each platform has different strengths and services. AWS provides a broad range of cloud services, Azure has strong integration with Microsoft technologies, and Google Cloud is known for its strengths in AI, Machine Learning, data, and Kubernetes.

Business requirements are important when selecting a cloud platform. Organizations should consider their budget, existing technologies, application requirements, scalability, security, performance, and future plans. For example, Azure is suitable for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Google Cloud is suitable for the AI research company because it needs AI, Machine Learning, and high-performance computing capabilities.

Acting as a Cloud Solutions Consultant taught me that selecting a cloud provider should be based on the client's actual needs instead of simply choosing the most popular platform. I learned that a consultant must understand the client's requirements first and then compare available services to recommend an appropriate solution.

My GitHub Cloud Computing Portfolio also improved after completing this mission. I added organized Markdown documentation, cloud platform research, comparison tables, client recommendations, screenshots, and a reflection. This activity helped me improve my understanding of multi-cloud environments and taught me how to present technical information in a more organized and professional way.
