# AWS Research

## Amazon Web Services (AWS)

### Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, networking, databases, security, analytics, and application development.

AWS allows organizations to use cloud resources without having to maintain all of their own physical infrastructure.

---

## Global Infrastructure

AWS operates a global cloud infrastructure consisting of Regions and Availability Zones.

An AWS Region is a geographic area where AWS provides cloud infrastructure. Availability Zones are separate locations within a Region that can be used to improve application availability and reliability.

This global infrastructure allows organizations to deploy applications closer to their users and design systems for high availability.

---

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services.

Through the console, users can create and manage resources such as virtual machines, storage, databases, networking resources, and security settings.

---

## Four Core AWS Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) provides virtual servers that can be used to run applications and workloads.

EC2 allows users to select computing resources based on their application requirements.

### 2. Amazon S3

Amazon Simple Storage Service (Amazon S3) provides object storage for files, application data, backups, and other information.

S3 is designed to provide scalable storage for different types of workloads.

### 3. Amazon VPC

Amazon Virtual Private Cloud (Amazon VPC) allows users to create logically isolated networks in AWS.

It can be used to configure networking components such as subnets, routing, and security controls.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources.

IAM can be used to manage users, permissions, roles, and access policies.

---

## Three Advantages of AWS

### 1. Broad Range of Services

AWS provides a large selection of cloud services covering many areas of information technology.

### 2. Scalability

AWS services can be scaled according to application and business requirements.

### 3. Global Infrastructure

AWS provides infrastructure in multiple geographic regions, allowing organizations to deploy applications in different locations.

---

## Typical Enterprise Use Cases

AWS can be used by organizations for:

- Website and application hosting
- Data storage and backup
- Database applications
- Enterprise application development
- E-commerce systems
- Data analytics
- Disaster recovery
- Scalable cloud infrastructure

---

## Summary

AWS provides a broad range of cloud computing services for organizations of different sizes. Its computing, storage, networking, and identity services provide the basic infrastructure needed to build and operate cloud applications.

AWS is particularly suitable for organizations that need flexibility and access to a wide variety of cloud services.
