# CCM101 – Cloud Computing

# Laboratory Activity 3 – Mission 3: Become a Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring and comparing three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The goal of this mission is to understand the core services offered by each cloud provider, compare their capabilities, analyze different business requirements, and recommend the most appropriate cloud platform for different client scenarios.

This activity also uses KillerCoda to investigate a Linux environment and relate the Linux server to possible cloud virtual machine services.

---

## Mission Objectives

After completing this laboratory activity, I should be able to:

- Explore major public cloud platforms.
- Identify the core services offered by AWS, Microsoft Azure, and Google Cloud Platform.
- Compare cloud services across different providers.
- Analyze business requirements and recommend appropriate cloud solutions.
- Create professional technical documentation using Markdown.
- Maintain and improve a GitHub Cloud Computing Portfolio.
