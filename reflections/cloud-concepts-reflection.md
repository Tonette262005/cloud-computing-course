# Cloud Concepts Reflection

## 1. Cloud Services I Use

Cloud computing is part of my everyday life because many of the applications I use rely on cloud technology. Three cloud services that I use regularly are:

- **Google Drive** – I use Google Drive to store my documents, assignments, and presentations. It allows me to access my files from any device with an internet connection.
- **Canva** – I use Canva to create presentations, posters, infographics, and other school-related projects. It helps me design my work without installing professional design software.
- **Facebook Messenger** – I use Messenger every day to communicate with my classmates, instructors, friends, and family through chats, voice calls, and video calls.

## 2. Service Model and Deployment Model

- **Google Drive**
  - **Service Model:** Software as a Service (SaaS)
  - **Deployment Model:** Public Cloud
  - **Reason:** Google Drive is a ready-to-use online application that lets users store and share files through the internet. It is available to anyone with a Google account.

- **Canva**
  - **Service Model:** Software as a Service (SaaS)
  - **Deployment Model:** Public Cloud
  - **Reason:** Canva provides online design tools that users can access through a web browser or mobile app without installing software. It is available to the public over the internet.

- **Facebook Messenger**
  - **Service Model:** Software as a Service (SaaS)
  - **Deployment Model:** Public Cloud
  - **Reason:** Messenger allows users to send messages, make voice and video calls, and share files online. It is accessible to millions of users through Meta's cloud infrastructure.

## 3. Git & GitHub for Cloud Projects

Version control is important when working with cloud infrastructure because it records every change made to project files. If a mistake occurs, previous versions can easily be restored. It also allows multiple developers to work on the same project without overwriting each other's work.

Git and GitHub make collaboration more organized by tracking changes, managing different versions of files, and allowing team members to review updates before merging them into the main project. GitHub also serves as a secure online repository where projects can be stored, backed up, and accessed from anywhere. As a BSIT student, learning Git and GitHub will help me develop better programming practices and prepare me for future cloud computing and software development projects.
