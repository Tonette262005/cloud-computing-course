# ☁️ Laboratory 01 – Welcome to the Cloud

## Mission Overview

Welcome to the Cloud is the first laboratory activity for CCM101 – Cloud Computing.

This activity introduces the basic responsibilities and working environment of a cloud engineer. The laboratory uses the KillerCoda Playground to provide a cloud-based Linux environment where I can practice Linux commands, system exploration, file and directory management, Markdown documentation, and GitHub version control.

The activity also requires the creation of a personal Cloud Computing Portfolio that will be used to document laboratory activities throughout the semester.

---

## 🎯 Objectives

After completing this laboratory activity, I should be able to:

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a professional GitHub repository.
- Document technical work using Markdown.
- Practice documentation methods used by cloud professionals.

---

## 🧪 Activities Performed

### Checkpoint 1 – Enter the Cloud

- Launched an Ubuntu Linux Playground using KillerCoda.
- Verified that the terminal was working.
- Created a new Linux user.
- Configured the user with a home directory and Bash shell.
- Added sudo privileges.
- Set a password.
- Logged into the new user account.
- Checked the current username.
- Checked the current working directory.
- Checked the hostname.

### Checkpoint 2 – Meet Your Environment

Investigated the Linux environment and collected:

- Linux Distribution
- Kernel Version
- CPU Information
- Total Memory
- Available Disk Space

The results were recorded in `system-information.md`.

### Checkpoint 3 – Build Your Workspace

Created the required workspace directories inside the home directory.

Created the `about-me.md` Markdown file inside the `Notes` folder and documented personal information.

### Checkpoint 4 – Create Your Cloud Computing Portfolio

Created a public GitHub repository for the CCM101 Cloud Computing portfolio.

The repository is used to store laboratory documentation, Markdown files, screenshots, and reflections.

### Checkpoint 5 – Document Your Mission

Created this laboratory README file and documented the mission overview, objectives, activities, commands, and skills learned.

### Checkpoint 6 – Capture Evidence

Created a `screenshots` folder to store evidence of the completed laboratory activities.
